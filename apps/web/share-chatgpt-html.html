How to share a ChatGPT page as a link

  1. Ask for one file. Tell ChatGPT: "Put the whole page in one HTML code block, with the CSS and JavaScript inside."
  2. Check it with Preview. ChatGPT shows a Preview option on HTML code blocks. If the page looks right there, it will look right on aired.
  3. Copy the code. Use the copy button on the code block.
  4. Paste it above and click Publish. Add a PIN or change how long it lasts if you like.
  5. Send the link. It opens in any browser, with no sign-in.

If Preview shows a React component rather than a page, ask ChatGPT to "rewrite this as plain HTML in one file" first. React code needs a build step and shows up blank on its own.

What happened to Canvas

In May 2026 OpenAI removed Canvas from its current models and replaced it with writing blocks and code blocks in the chat itself. Paid users can still reach Canvas for a limited time through older models. For a web page, the code block is now the place to get it: copy it from there and publish it as above.

Questions

How do I share a ChatGPT HTML preview with someone who doesn't use ChatGPT?

Copy the HTML code block, paste it on aired and publish. Send the link; it opens in any browser without a ChatGPT account.

Does a shared ChatGPT chat link show the page?

OpenAI's help article says shared links include the conversation, responses, images and files, and doesn't mention code previews. To be sure people see the page, publish the HTML and send that link.

Is ChatGPT Canvas gone?

OpenAI replaced Canvas in its current models with writing blocks and code blocks in May 2026. Paid users can still use it for a limited time through older models.

Why is my published page blank?

The code is probably a React component. Ask ChatGPT to rewrite it as plain HTML in one file, with the CSS and JavaScript inside, then publish that.

Can I password-protect the link?

Yes. Type a PIN before you publish. Visitors enter it before the page loads.

Is it free?

Yes. Publishing and viewing are free, with no account and no view limit.
