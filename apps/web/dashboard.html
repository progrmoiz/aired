    Connect your AI tools

    Let Claude, ChatGPT or Cursor publish for you. Ask for a link and the page lands here, in your account.

    Claude

    claude.ai and the Claude app

    1. In Claude, open Settings → Connectors and add a custom connector.
    2. Paste this link, then sign in to aired and choose Allow.
    https://aired.sh/mcp/account

    Then ask: “Publish this as a link.”

    ChatGPT

    chatgpt.com and the ChatGPT app

    1. In ChatGPT settings, add a custom connector. Some plans need developer mode turned on first.
    2. Paste this link, then sign in to aired and choose Allow.
    https://aired.sh/mcp/account

    Then ask: “Put this page online with aired.”

    Cursor

    The Cursor editor

    1. Click Add to Cursor and confirm in Cursor.
    2. When Cursor asks, sign in to aired and choose Allow.
    Add to Cursor

    Then ask the agent to publish the page you're working on.

    Claude Code

    Also Codex, Windsurf and other coding agents

    1. Run this once in your terminal. It teaches your agent to publish.
    npx skills add progrmoiz/aired -g
    1. Sign in so pages land in this account.
    npx aired login

    What a connected tool can do

    You can remove it from the tool's settings at any time.

    • Publish pages to your account, and update or delete them
    • List the pages you already have
    • See your developer keys or billing, or delete your account
    Developer keysFor scripts, CI and tools that can't sign in

    A key lets anything that has it publish to this account. Keep it secret, like a password. Using a client without MCP sign-in? Send the key as a header on https://aired.sh/mcp. API and CLI docs →
