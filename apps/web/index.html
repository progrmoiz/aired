    Read the docs
    Do I need an account?

    No. Paste or drop the file and you get a link. Sign in with GitHub only if you want your pages in one place.

    Does the person I send it to need anything?

    Just a browser. No account, no app, no sign-in.

    How long does a link last?

    Seven days by default. You can pick 1 hour, 1 day, 30 days, or never before you publish.

    Can I keep a page private?

    Add a password before you publish. Pages without an account are hidden from search engines.

    What can I publish?

    Any single HTML page up to 2 MB: reports, dashboards, decks, games. Scripts and styles run as written.

    Is aired free?

    Yes. Publishing and viewing are free, and the code is open source. Paid plans for your own domain and open tracking are coming.
